# baymaxssh\n\nSSH + WebSocket + SSL VPN server installer and management panel for Debian/Ubuntu servers.\n\n> Important: review the script before running it on a production server. It installs and configures OpenSSH, Dropbear, a dual-mode WebSocket/SSH proxy, stunnel TLS, optional Xray (VMess/VLESS/Trojan), optional SlowDNS, optional Hysteria UDP, and optional abuse protection.\n>\n> The installer creates default SSH accounts with the password shown during installation. Change or remove those accounts immediately after setup, and do not expose credentials in public configuration files.\n\n## Install\n\n```bash\ncurl -fsSL https://raw.githubusercontent.com/kelvinsonatech/baymaxssh/main/ssh-ssl-setup.sh -o ssh-ssl-setup.sh\nchmod +x ssh-ssl-setup.sh\nsudo ./ssh-ssl-setup.sh\n```\n\n## Main services\n\n| Service | Ports | Purpose |\n| --- | --- | --- |\n| OpenSSH | 22 | Direct SSH and management backend |\n| WebSocket/SSH proxy | 80 | HTTP payload and raw SSH compatibility |\n| stunnel TLS | 443, 447 | TLS payload and direct TLS-to-SSH |\n| Dropbear | 109, 143 | Alternate direct SSH targets |\n| Xray | Allocated Cloudflare-friendly ports | Optional VMess, VLESS, and Trojan variants |\n| SlowDNS | UDP 53 | Optional DNS tunnel |\n| Hysteria | UDP 20,000-50,000 | Optional UDP tunnel with port hopping |\n\n## Management\n\nAfter installation, run `menu` as root. The panel manages SSH users, services, Xray accounts, SlowDNS information, abuse protection, Hysteria users, and Fast DNS.\n\n## Notes\n\n- The script is intentionally delivered as one self-contained file so it can be fetched and reviewed before execution.\n- Protocol paths and port handover logic are kept together to avoid configuration drift.\n- The installer is designed for Debian/Ubuntu systems with systemd and apt.\n- Always take a server snapshot before installing or upgrading a production VPN stack.\n
